# ADR 0001 — Versions figées

- **Date** : 05/10/2026
- **Statut** : accepté
- **Contexte** : annexe E du cahier, NF-08 (reproductibilité). Versions vérifiées avec `npm view <paquet> version` (et `engines`, `peerDependencies`) le 05/10/2026.

## Décision

Toutes les dépendances sont figées **exactement** (`save-exact=true` dans `.npmrc`, aucune plage `^`). `engine-strict=true`. `--legacy-peer-deps` n'est jamais utilisé : `npm install` passe sans conflit de pairs.

Runtime : `engines.node` = `^22.19.0 || >=24.0.0`, `.nvmrc` = `24`. Le poste a Node **22.23.2** et npm 11.6.0 : tous les `engines` des paquets sont satisfaits (le plus exigeant est `write-file-atomic` 8.0.0 : `^22.22.2`, et il n'est pas installé, voir ADR 0005).

## Conséquences

- Une montée de version passe par un nouvel ADR et par la batterie complète (`npm test`, `npm run test:ats`).
- TypeScript 6 n'inclut plus automatiquement `@types/*` : `"types": ["node"]` est déclaré dans `tsconfig.base.json`.
