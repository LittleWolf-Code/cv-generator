# Rapport de recette du MVP (§12.6)

- **Version recettée** : lot 8 (modèle visuel, thèmes et recette), sur le commit du lot 7 (`07725c4`) et les changements du lot 8.
- **Date** : 06/10/2026.
- **Poste** : Windows 11, Node 22.23.2, Typst 0.14.2 (compilateur Node 0.7.0), LibreOffice installé (T-DOCX-03 mesuré). Poppler 26.09.0 installé après la recette dans le navigateur : la batterie ATS a ensuite été rejouée avec les deux extracteurs (écart 6).

Vérifié : la candidature est rouverte après un rechargement, et les exports suivants sont rangés dans la candidature. |

## Ce que la recette ne couvre pas (à faire par l'utilisateur)

- **Claude réel** : les prompts `adapter-a-une-offre`, `importer-mon-cv` et `rediger-lettre` ont été joués par un client MCP qui reproduit les appels de Claude. Le comportement de Claude Desktop (configuration MSIX, prompts, §15 point 5) et de Claude Code sur vos données reste à vérifier.
- **Données réelles** : l'essai à blanc de votre export LinkedIn (colonnes de F-IMP-02), puis l'import, se font avec votre accord.
- **Contrôles manuels du §12.5** : Bloc-notes, parseur d'OpenResume, vérificateur de rxresu.me et mots-tests, décrits pas à pas dans le README.
