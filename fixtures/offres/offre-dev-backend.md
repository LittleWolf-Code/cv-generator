# Développeur backend H/F – Exemple Logistique (offre fictive)

**Référence** : EXL-2026-042 · **Lieu** : Lyon (69) · **Contrat** : CDI · **Télétravail** : 2 jours par semaine

## L'entreprise
Exemple Logistique est une entreprise fictive de 300 personnes qui édite une plateforme de suivi des livraisons pour la grande distribution.

## Missions
- Concevoir et développer des API REST en Python (FastAPI) et en Node.js.
- Modéliser les données dans PostgreSQL et optimiser les requêtes.
- Mettre en place l'intégration et le déploiement continus (CI/CD) avec GitLab CI.
- Écrire des tests automatisés et participer aux revues de code.
- Superviser les services en production (Prometheus, Grafana) et participer à l'astreinte.

## Profil recherché
- Diplôme d'ingénieur ou master en informatique.
- 3 ans d'expérience minimum en développement backend.
- Maîtrise de Python et de SQL exigée ; la connaissance de Go est un plus.
- Pratique de Docker et de Kubernetes souhaitée.
- Anglais technique courant.
